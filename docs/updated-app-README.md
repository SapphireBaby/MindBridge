## About

MindBridge is an **AI-powered behavioral training system** that puts you inside difficult real-world conversations — then debriefs you like a coach.

Emotional intelligence (EQ) is one of the most important skills for success in relationships, career, and life — yet it's rarely taught. MindBridge makes EQ **trainable, repeatable, and measurable** through immersive roleplay powered by Claude AI.

---

## Features

| Feature | Description |
|---|---|
| 🎭 **AI Roleplay Engine** | Realistic, escalating conversations that don't let you off the hook |
| 🧠 **Personalized EQ Debrief** | What landed, what missed, and what to improve — after every session |
| 📈 **Progress Tracking** | Visualize emotional intelligence growth over time |
| 🗂️ **Scenario-Based Learning** | Real situations: salary raise, boundary-setting, grief calls, and more |

---

## Tech Stack

- **Frontend:** React 18 + Tailwind CSS
- **AI Engine:** Claude API (roleplay + behavioral analysis)
- **Build Tool:** Vite
- **Platform AI:** ERNIE + MeDo (full-stack generation)

## Getting Started

```bash
git clone https://github.com/Oneseco-Media/mindbridge-app.git
cd mindbridge-app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
